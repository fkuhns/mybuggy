🚗 Buggy Zone Editor

1. Distance zones

The buggy measures how far away things are, in inches. Each distance falls into a zone. A zone starts where the zone before it ends. Zone 1 always starts at 0. The last zone goes on forever (∞). Pick light colors for each zone too.

2. What should the motors do?

Each box is one situation: row = the zone in front of the buggy, column = the zone behind it. For each box, set which way each wheel turns (forward or reverse) and how fast it goes (0–100).

3. Test drive (pretend)

Move the sliders to pretend something is near the buggy. The matching box above gets highlighted, and the buggy below shows what it would do.
